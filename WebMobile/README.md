# Poker Orbit Web Mobile Template

Mobile-first browser shell for Poker Orbit, separate from the Unity project.

## Screens

- Splash screen with BSG placeholder branding
- Lobby
- Game screen
- Settings page

## Run

```powershell
cd "D:\BIG-SLICK-GAMES\GAMES\Poker Orbit\WebMobile"
npm start
```

Open `http://localhost:4280`.
